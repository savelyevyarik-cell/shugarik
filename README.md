# ОКТАН — сайт технического центра по ремонту автотехники (Москва)

Портфолио-проект. Многостраничный сайт-презентация: тёмная «инженерная» эстетика,
3D-объект в hero, scroll-storytelling, page transitions, кастомный курсор.

## Стек

Чистый HTML / CSS / JS без сборщика.

| Слой | Технология |
|---|---|
| 3D | Three.js 0.160 (ESM через importmap, CDN unpkg) |
| Анимации | GSAP 3.12 + ScrollTrigger |
| Плавный скролл | Lenis 1.1 |
| Шрифты | Google Fonts: Unbounded, Manrope, JetBrains Mono |

> Next.js не использован сознательно: в среде, где проект собирался, отсутствовал
> Node.js/npm, поэтому собрать и проверить Next-приложение было невозможно.
> Архитектура страниц при этом полностью соответствует ТЗ, а статика деплоится
> на Vercel без шага сборки.

## Структура

```
avtoremont-msk/
├── index.html          Главная: прелоадер, 3D-hero, маркизы, цифры,
│                       горизонтальная лента услуг, процесс, отзывы, CTA-форма
├── services.html       Услуги: фильтр по типу работ, аккордеон, цены «от», сроки
├── about.html          О сервисе: история, оборудование, таймлайн, команда, допуски
├── works.html          Работы: слайдер «было — стало», 6 кейсов
├── contacts.html       Контакты: тёмная карта, часы, форма записи с валидацией, FAQ
├── css/
│   └── style.css       Дизайн-система (токены) + все компоненты
├── js/
│   ├── chrome.js       Сквозные элементы: шапка, полноэкранное меню,
│   │                   шторка перехода, прогресс-бар, футер
│   ├── app.js          Вся интерактивность: прелоадер, Lenis, курсор, magnetic,
│   │                   split-text reveal, счётчики, маркизы, horizontal scroll,
│   │                   аккордеон, фильтры, «было — стало», валидация форм
│   └── hero3d.js       Three.js сцена: тормозной диск + суппорт
├── vercel.json         Заголовки и настройки роутинга
└── README.md
```

Шапка/меню/футер собираются из `js/chrome.js` — один источник правды на все
страницы. `chrome.js` подключён с `defer` **до** `app.js`, поэтому к моменту
инициализации логики DOM уже готов. Для no-JS на главной есть `<noscript>`-навигация.

## Как запустить локально

Нужен любой статический сервер — `file://` не даст работать ES-модулям Three.js.

```bash
npx serve .
```

```bash
python -m http.server 5173
```

Дальше открыть `http://localhost:5173`.

## Деплой на Vercel

Сборка не нужна: Framework Preset — **Other**, Build Command — пусто,
Output Directory — корень проекта.

Через CLI:

```bash
npm i -g vercel
```

```bash
cd avtoremont-msk && vercel
```

На вопросы отвечаем: Set up and deploy — `y`, Framework — `Other`,
Build/Output — оставить пустыми. Продакшн-деплой:

```bash
vercel --prod
```

Через веб-интерфейс: залить папку в репозиторий GitHub → vercel.com → Add New
Project → Import → Framework Preset **Other** → Deploy.

## Точка интеграции форм

Сейчас отправка имитируется (`setTimeout` в `initForms`, `js/app.js`).
Чтобы подключить реальный бэкенд, замените этот блок на `fetch` — например,
на Vercel-функцию `api/lead.js` или на внешний сервис (Formspree, Telegram Bot API):

```js
const res = await fetch('/api/lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(Object.fromEntries(new FormData(form)))
});
```

Валидация, маска телефона и экран успеха уже готовы и от транспорта не зависят.

## Доступность и производительность

- Контраст основного текста `#EDEFF2` на `#0A0B0D` — около 15:1.
- Приглушённый текст `#A5ACB5` — около 8:1. Акцент `#FF4D0F` используется
  на тёмном фоне для крупных элементов и на белом тексте внутри заливки кнопок.
- Skip-link, видимый фокус, `aria-expanded` у аккордеонов и бургера,
  `role="slider"` + управление стрелками у «было — стало».
- `prefers-reduced-motion`: отключаются прелоадер, split-reveal, параллакс,
  Lenis, кастомный курсор, зерно и 3D.
- 3D отключается при ширине ≤ 768 px, отсутствии WebGL и при `hardwareConcurrency ≤ 4`;
  рендер останавливается, когда hero вне вьюпорта или вкладка неактивна.
